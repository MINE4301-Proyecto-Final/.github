# MINE4301-Proyecto-Final
Este repositorio registra los resultados relacionados con la construcción de productos de datos realizados durante el curso MINE4301 Proyecto final.

Los estudiantes resuelven problemas que parten de los datos, producen información, muestran la transformación de los datos para el logro de un objetivo que genera valor en una organización, ponen en evidencia el ciclo de vida de la información y producen soluciones que muestran el dominio en la incorporación, integración y producción de la tecnología apropiados para la solución, siguiendo un proceso de calidad y trabajando en equipo. Los equipos varían entre 2 y 4 integrantes y los repositorios tienen una estructura similar a la siguiente:

- Carpeta Documentos
- Carpeta Datos
- Carpeta Modelos
- Carpeta Notebooks
- Carpeta Codigo Fuente
